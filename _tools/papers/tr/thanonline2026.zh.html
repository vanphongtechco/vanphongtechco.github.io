在线煤质分析系统在林同铝业公司锅炉燃烧运行中的应用潜力

阮秋贤 博士（Nguyen Thu Hien）、黎清平 博士（Le Thanh Binh）

越南煤炭矿产工业集团（Vinacomin）能源与矿山机械研究院（IEMM） · E-mail: binhimeme@gmail.com

2026年全国矿业科学技术研讨会，林同省，2026年10月7–10日

摘要

本研究评价了在线煤质分析系统在支持林同铝业公司（TKV）循环流化床锅炉运行优化方面的应用可能性。基于公司实际煤质数据和运行条件，研究分析了发热量、水分、灰分和硫分的波动情况，比较了各种在线分析原理，并选定了PGNAA技术。根据发热量与给煤量之间的关系，研究估算潜在燃料节约率约为1.23%，相应的潜在节煤量约为2,848吨/年，节约价值约为100.61亿越南盾/年。总投资约465亿越南盾，运行维护费用约12.34亿越南盾/年，估算投资回收期约为8年。除经济效益外，在线煤质分析系统还能够辅助调整燃烧工况，提高运行稳定性，减少实验室分析工作量，并为DCS系统提供燃料质量数据，从而有助于提高燃料利用效率，实现公司锅炉运行工作的现代化。

关键词：在线煤质分析；PGNAA；循环流化床锅炉；煤发热量；运行优化；燃料节约

1. 问题的提出

循环流化床（CFB）锅炉能够燃用多种燃料，但其燃烧效率、燃料消耗水平和运行稳定性在很大程度上取决于燃料特性以及给燃料–供风工况［2］。对于煤而言，发热量、水分、灰分和硫分的波动会影响锅炉的能量平衡、燃烧过程和运行参数。因此，及时确定燃料质量是优化运行的依据之一。

林同铝业公司（TKV）拥有2台CFB锅炉，每台额定蒸发量170 t/h，蒸汽参数5.29 MPa/450 °C，由DCS系统进行控制和监视［1］。目前煤质通过采样和实验室分析进行控制。该方法可靠性高，但从采样到获得结果之间存在时滞，因而无法提供给煤过程中燃料波动的连续信息。

在线煤质分析系统能够连续采集煤流质量信息，为提前调整燃料给入量提供依据。与DCS集成后，煤质数据可作为现有反馈回路的补充前馈信号［3］。

本研究评价在线煤质分析系统在林同铝业公司的应用可能性，选择合适的测量原理，量化由发热量波动带来的潜在燃料节约，并对投资方案的经济效益进行初步评价。

2. 煤质现状与燃料控制

2.1. 实际煤质特性

公司所用末煤的质量存在波动。实际数据表明，发热量、水分、灰分和硫分在一定范围内变化，影响燃料给入要求和锅炉运行条件。主要指标的波动范围汇总于表1。

结果表明，各煤质指标的波动幅度较大。这种波动要求对燃料质量进行连续监测，而不是仅依靠各采样时刻的分析结果。本研究选取发热量波动来量化其对给煤需求和潜在燃料节约的影响；其余指标则从技术和运行角度加以考虑。

2.2. 煤的采样与分析现状

目前，入炉煤质量采用在输煤线上人工采样并在实验室分析的方法进行控制。煤样采样频率为每小时1次。每个生产班次内，收集各子样，经混合和缩分形成一个代表该运行班次的样品。代表性样品送至实验室测定发热量、水分、灰分、硫分等主要指标及相关参数。

[图1 — 见原文PDF第2页] 林同铝业公司锅炉输煤及燃料分配系统

现行方法具有分析可靠的优点，适用于煤质控制工作。但采样、制样和分析过程会产生时滞，从采样到获得结果的时间可能长达约8–16小时。因此，分析结果主要用于使用后的评价和控制，限制了在煤质变化时及时进行调整的能力。

2.3. 在线煤质分析系统的必要性及要求

对于CFB锅炉，煤质波动会改变维持相同输入能量所需的燃料给入量。连续更新的煤质信息可使运行人员及早发现燃料变化，并相应调整给煤工况。

在线煤质分析系统能够连续测定给料煤流的煤质特性，为运行监视和调整提供实时数据。与现有DCS系统集成后，煤质数据可作为补充前馈信号，辅助提前修正燃料给入量和燃烧工况，而反馈控制回路继续维持运行过程的稳定。

因此，应用在线煤质分析系统并非旨在完全取代实验室分析方法，而是增加连续监测能力，缩短控制系统的响应时间，提高林同铝业公司的燃料利用效率。

2.4. 分析技术的选择

可用于在线煤质分析的技术包括XRF、NIR和PGNAA。XRF能够测定元素组成，但直接在煤流上测量时需考虑穿透深度和物料不均匀性的影响。NIR测量速度快，不使用放射源，但其可靠性在很大程度上取决于校准模型及建模所用数据的范围。

PGNAA利用中子激发物料并分析其发射的伽马射线。中子–伽马法具有深穿透测量能力，适用于皮带输送机上大流量物料的成分分析［5］。PGNAA的局限在于投资成本较高，辐射安全管理要求也较高。

[图2 — 见原文PDF第3页] 皮带式煤质分析仪的结构

根据在煤流上连续测量、测量代表性以及与DCS数据集成能力的要求，本研究选定PGNAA作为研究方案的技术原理。

3. 研究方法与结果

3.1. 投资方案与运行费用

在线煤质分析系统的总投资包括建筑工程费、设备费、项目管理费、工程建设投资咨询费、其他费用和预备费，预计总投资为465亿越南盾。

运行过程中，系统会产生Cf-252源更换费用和定期维护费用。源更换费用约为每次30亿越南盾；按2.645年的半衰期折算，年均费用约为11.34亿越南盾。定期维护费用约为1亿越南盾/年。运行维护总费用约为12.34亿越南盾/年。

[图3 — 见原文PDF第4页] 安装于永新2号火电厂（Vinh Tan 2）的PGNAA分析设备

3.2. 潜在燃料费用节约的估算

公司所用煤的分析数据表明，运行过程中发热量存在波动。研究中采用的特征值为：最小值Qmin = 5,700 kcal/kg，平均值Qtb = 5,945 kcal/kg，最大值Qmax = 6,100 kcal/kg［7］。

由于研究所用数据集以最小值、最大值和平均值为特征，故采用三角分布作为描述发热量波动的近似模型。分布参数由上述特征值确定［4］。分布的众数按下式确定：

Qm = 3Qtb − Qmin − Qmax = 3×5,945 − 5,700 − 6,100 = 6,035 kcal/kg    (1)

发热量的概率密度函数为：

f(Q) = 2(Q − Qmin) / [(Qmax − Qmin)(Qm − Qmin)]，Qmin ≤ Q ≤ Qm；
f(Q) = 2(Qmax − Q) / [(Qmax − Qmin)(Qmax − Qm)]，Qm ≤ Q ≤ Qmax    (2)

式中，f(Q)为按三角分布的发热量概率密度函数；Q为按所建分布变化的煤发热量。

假设锅炉热负荷和效率不变，所需给煤量与煤的发热量成反比：

B(Q) × Q = const

因此，相对于使用平均发热量Qtb煤的情况，给煤量的相对变化按下式确定：

R(Q) = ∫QminQmax |Qtb/Q − 1| f(Q) dQ × 100    (3)

将Qmin = 5,700 kcal/kg、Qm = 6,035 kcal/kg、Qmax = 6,100 kcal/kg和Qtb = 5,945 kcal/kg代入式（3），计算结果为：

RQ ≈ 1.23%

RQ值反映了给煤量相对于煤发热量稳定在平均水平情况下的平均相对偏差。该值在经济效益评价中用作潜在燃料节约率。这是一个潜在水平（上限），其计算假设在缺乏实时煤质信息时，给煤量未能根据发热量波动及时修正；实际节约水平需在系统安装后通过试运行和对比加以确定。

根据林同铝业公司的运行数据，2022–2025年期间末煤平均用量为231,508吨/年。按1.23%的节约率计算，可节约的末煤量估计约为2,848吨/年。按加权平均煤价3,533,305越南盾/吨计算，相应的燃料费用节约为：

Sthan = 231,508 × 1.23% × 3,533,305 ≈ 100.61亿越南盾/年    (4)

3.3. 劳动力使用效益

在初期阶段，仍保留采样和实验室分析工作用于对比。在线系统稳定后，对比频率可降至每班1个样品。按现行方式，每班需要1个工日完成采样、制样和分析；每天3班，相当于每天3个工日。转为对比模式后，工作量估计仅相当于每天1个工日，从而可从煤的采样和分析工作中节省约每天2个工日。

按现有部门人均人工成本15,773,487越南盾/人·月计算，可节约的等效人工费用为：

SNC = 2 × 15,773,487 × 12 = 378,563,688越南盾/年    (5)

3.4. 技术、运行和环境效益

除节约燃料和劳动力外，在线煤质分析系统还可连续提供入炉煤发热量、水分、灰分和硫分等信息。这些数据可用于辅助根据燃料波动调整给煤量和燃烧工况，从而有助于维持锅炉运行过程的稳定。

硫分信息还为根据燃料特性调整入炉石灰石量提供了依据，有助于控制SO2排放。同时，按本研究估算的幅度减少耗煤量，可有助于减少燃煤过程中产生的灰渣量和CO2排放。

在线系统提供的燃料质量数据可集成到DCS系统中，用于运行监视和调整。在初期阶段，在线数据需与实验室分析结果进行对比，以评价其准确度和稳定性，然后才能在运行调整中常规使用。

由于系统投运后尚无足够的运行数据，研究中未对减少石灰石、灰渣、CO2、化学药品和分析耗材等效益进行量化。因此，这些效益未计入经济效益计算。

3.5. 投资效益评价

投资效益根据总节约价值、运行维护费用、借款资金成本和企业所得税进行评价。

可量化的年均总节约价值包括约100.61亿越南盾的煤费节约和约3.79亿越南盾的等效人工价值，合计：

STK = 100.61 + 3.79 = 104.40亿越南盾/年    (6)

运行维护费用约为12.34亿越南盾/年。按全额借款465亿越南盾、期限8年、年利率8.5%、等额还本并按实际贷款余额计息的方案，8年利息总额约为159.75亿越南盾，相当于年均19.97亿越南盾。

节约价值与运行维护费用及借款利息之间的税前差额为：

S税前 = 104.40 − 12.34 − 19.97 = 72.09亿越南盾/年    (7)

企业所得税按上述差额的20%计算：

CTNDN = 72.09 × 20% = 14.42亿越南盾/年    (8)

税后净收益：

S净 = 72.09 − 14.42 = 57.67亿越南盾/年    (9)

投资回收期为：

THV = 465 / 57.67 ≈ 8年    (10)

4. 结论与建议

研究表明，采用PGNAA技术的在线煤质分析系统在林同铝业公司（TKV）锅炉燃烧运行中具有应用潜力。连续提供煤质信息（尤其是发热量）可辅助调整燃料给入量，提高运行稳定性，增强对燃烧过程的控制能力。

按约1.23%的潜在燃料节约率，可节约煤量约2,848吨/年，相应价值约100.61亿越南盾/年。预计总投资约465亿越南盾，运行维护费用约12.34亿越南盾/年，估算投资回收期约8年。除经济效益外，在线煤质分析系统还能够辅助调整燃烧工况，提高运行稳定性，减少实验室分析工作量，并为DCS系统提供燃料质量数据，从而有助于提高燃料利用效率，实现公司锅炉运行工作的现代化。

建议：公司考虑按以下路线图在锅炉输煤线上部署在线煤质分析系统：（i）初期与实验室分析并行运行，按照ASTM D6543指南［6］评价设备的准确度和稳定性；（ii）根据实际运行数据，重新确定燃料节约水平，并量化尚未计入的效益（石灰石、灰渣、CO2排放、分析耗材）；（iii）数据经验证后，将煤质信号集成到DCS系统中，以辅助调整给煤量和燃烧工况。
