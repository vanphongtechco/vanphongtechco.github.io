论静态与动态条件下岩石破碎参数之间的关系

V. I. Bolobov, V. A. Plashchinsky, S. V. Borisov, B. Le-Thanh

《选矿》（Obogashchenie Rud），2021年，第5期，第3–9页 · UDC 622.023 : 539.422.2 · DOI: 10.17580/or.2021.05.01

摘要

本文介绍了在准静态和动态加载条件下，半球形压头压入砂岩板时砂岩板接触破碎与劈裂试验的方法和结果。研究发现，在准静态条件下岩石接触破碎时，劈裂过程的功和比能耗明显小于冲击条件下的相应值。结果表明，冲击时劈裂砂岩板所需的力约为静态加载条件下所需力的两倍。

关键词：砂岩板，半球形压头，准静态加载，冲击作用，接触破碎，劈裂，刚度系数。

引言

对冲击条件下以及准静态条件下（即破岩工具相对缓慢地侵入时）岩石破碎过程的研究，多年来一直是大量科学研究的课题。然而，迄今为止，关于这些过程发生机理的相似性和差异性仍未形成统一的认识。

例如，文献[1]指出，在动态和静态载荷作用下岩石逐层破碎的机理具有相似性：在动态条件下破碎过程的初始阶段，被破碎岩石的表层发生粉碎分散，工具进一步侵入时岩石发生接触强化；从物理角度看，这与将刚性不变形冲头（压模）准静态压入固体表面的过程类似。

文献[2]的作者认为，无论在静态还是动态加载下，岩石破碎过程的最终阶段——连续性丧失——只是终结性的一步，而破碎过程本身的特征是在不同尺度层次上结构缺陷的依次萌生和发展。同时，在动态加载下与在静态加载下一样，破碎过程并非瞬时完成，而是以随时间分布的损伤累积为特征，即动态破碎是一个多阶段过程。反过来，在静态加载下，岩石的微破碎以准静态方式进行，而随后主裂纹的扩展则以接近介质中声速的速度按动态方式进行。

根据列宁格勒矿业学院所开展工作的结果，文献[3]的作者指出，无论是动态还是静态压入冲头，在接触面下方的岩石中都会形成压密核。由于压密核沿大致垂直于压入力作用方向扩张，产生裂纹，导致块体表面出现崩落坑或块体断裂。该研究还发现，与静态条件相比，在动态条件下破碎物体所需的能量显著增加。例如，使用球形工作面冲头沿层理方向破碎煤（σсж = 30 MPa）时，这两种能量分别为12.5 J和2.0 J，作者将其解释为冲击时岩石对塑性变形和破碎的抗力增大。

其他研究（例如[4, 5]）的作者也得出了同样的结论。例如，文献[4]表明，由静态大切屑剥落转为冲击剥落时，破碎无烟煤的能耗由1.18 MJ/m3增至1.90 MJ/m3，破碎黏土页岩的能耗由1.83 MJ/m3增至6.48 MJ/m3，即分别增加了1.6倍和3.5倍。

文献[6–8]的作者将岩石破碎比能耗的上述差异解释为：动态破碎时用于形成新表面的能量所占比例增大，因为大部分能量用于形成压密核，而只有很小一部分用于使碎块从岩体上分离。

如果说几乎所有研究都一致认为动态载荷下破碎过程的能耗显著高于静态载荷，那么关于静态和动态条件下破碎岩石所需力的差异，文献中的观点则不尽相同。

例如，文献[9]给出了钻头齿冲击侵入Indiana石灰岩（σсж = 40–130 MPa）的数据，并与静态压入的结果进行了比较。研究发现，冲击时和静态试验中的变形曲线具有相似的特征；同时，无论作用速度如何，静态和动态条件下破碎石灰岩所需的力大致相同。R. M. Eigeles [10]在其研究中也未发现静态和动态加载条件下破碎岩石所需力的数值之间存在显著差异。

与此同时，另一些研究[4, 5, 11–13]则指出，岩石的破碎抗力随侵入速度的增加而增大。例如，将楔子压入石灰岩块体时，得到的“力–侵入深度”曲线在静态条件下和以不同速度进行的冲击作用下各不相同[14]。由文献[14]图17的曲线可以推断，动态条件下对应岩石破碎时刻的力是静态加载下破碎力的3倍（碰撞速度3.1 m/s时）至6倍（5.4 m/s时）。有关冲击条件下和准静态条件下岩石破碎的其他信息见文献[15–23]。

本文采用试验与计算相结合的方法，对上述关于静态和动态条件下岩石破碎所需力的评价分歧进行了检验。

试验方法

破碎对象为Osinovsky岩体的砂岩，按M. M. Protodyakonov分级其坚固性系数f = 4，单轴抗压强度σсж = 82–112 MPa，制成40×40 mm、厚度δ = 10、15、30 mm的板材，沿层理方向从整块岩石上切割而成。侵入工具为锥形压头，其钝化部位为半径R = 3 mm的半球面，固定在长度L = 175 mm、质量M = 2 kg的圆柱杆上，由硬度约60 HRC的У8工具钢制成。

准静态条件下的试验在Zwick ZHU 187.5试验机上进行，即将压头以相对缓慢的速度（1.3·10–5 m/s）压入板材表面中点（图1），直至板材劈裂，同时记录力N与试验机横梁位移h的关系曲线，并据其形态确定：

  • 板材劈裂前压头侵入岩石的最大深度αр；
  • 劈裂力Nр；
  • 压头–岩石系统的刚度系数gст；
  • 劈裂功Aр；
  • 劈裂比能耗Aр.уд = Aр/Fр，其中Fр为劈裂碎块所形成的表面面积；
  • 接触破碎应力σк.р = N/Fк，其中Fк为压头与岩石的接触面积。
[图1 — 见原文PDF第5页] 准备试验的Zwick ZHU 187.5试验机（a）及压头压入砂岩板时工具的状态（b）

动态条件下的试验在试验台[24]上进行，该试验台可使同一工具从给定高度H在管状导向套内自由下落，由压头对板材施加冲击。冲击能量（Qmax = 10 J）和碰撞速度（vmax = 2.2 m/s）根据下落工具的质量及其下落高度计算。在同一批试验中，通过在板材下方放置与NI USB 6008模数转换器相连的PK 1000压电式力传感器，记录冲击载荷示波图，并据其形态确定冲击时达到最大力的时间tm。

在第一组动态试验中，使用测量误差为0.01 mm的百分表，确定冲击时板材接触破碎所形成的崩落坑深度αл与冲击能量Q之间的关系。对于每一能量值，在板材（δ = 30 mm）上彼此间距不小于三倍坑径的不同点施加10次冲击，并据此计算αл的算术平均值及其标准差σα。

在第二组试验中，确定冲击板材表面中点时劈裂厚度为10 mm和15 mm板材所需的最小能量Qр，以及劈裂过程的比能耗Qр.уд = Qр / Fр。

[图2 — 见原文PDF第6页] 压头压入砂岩板时力与试验机横梁位移关系的典型曲线

在初始阶段I，位移发生时载荷无明显增加；在阶段II，载荷按线性关系增长，与文献中所描述的关系相近。由于在位移阶段I岩石上没有压头侵入的痕迹，可以推断该阶段对应于消除试验机夹具各运动部件之间的间隙，因此只有曲线的阶段II对应于压头的侵入，图中以α表示该位移。将N = f(α)关系以直线外推，确定其与位移轴的倾角β，取其正切值作为准静态条件下压头–板材系统的刚度gст，并由此得出结论：压头侵入时砂岩接触破碎的载荷特性可用N = gстα形式的力函数描述。

接触面积Fк取为压头侵入部分表面的投影面积，按公式Fк = 2πα(2R – α)计算[25]。由于R（3 mm）明显大于α（不超过0.37 mm），Fк = f(α)关系接近线性，因此砂岩发生接触破碎时的应力σк.р = N/Fк在整个α范围内取为常数。

根据所确定破碎参数αр、Nр的平均值，计算板材劈裂功Aр = (αрNр) / 2。考虑到破碎板材的形态，Fр取为劈裂缝长度与板材厚度的乘积。

由表中数据可见，随着板材厚度的增加，参数αр、Nр、Aр增大，而Aр.уд、gст、σк.р无明显变化。同时，所得Aр.уд值（约830 J/m2）明显高于文献[1]中用楔子劈裂砂岩板时确定的该参数值（60–90 J/m2），这可以用岩石破碎方式的不同来解释：文献[1]中是沿碎块全长施加作用，而本文中仅为点接触。

冲击时板材劈裂参数的计算

考虑到试验中的冲击工具是长度相对较小的弹性元件，假定可以忽略波动过程对其冲击参数的影响，工具与岩石的相互作用过程可以用V. B. Sokolinsky的二元经典冲击系统方程[25]描述，并将载荷特性表示为在准静态条件下确定的线性函数N = g1α：

αm = √(2Q* / g1),    (1)
Nm = √(2g1Q*),    (2)
tm = π / (2√(m / g1)),    (3)

式中：αm为工具压头侵入岩石的最大深度；Nm为最大冲击力；tm为接触破碎时达到最大力的时间以及板材劈裂时的冲击持续时间；m为冲击工具的质量；g1为冲击系统的接触刚度；Q*为用于破碎岩石的冲击能量。

假定在按式(1)–(3)计算冲击参数时，可取表1中gст的平均值作为系统的刚度系数g1。由于冲击时冲击工具的能量只有一部分用于破碎岩石（对于砂岩约为54 % [26]），其余部分消耗于向周围环境的热损失、工具的弹性变形以及其接触表面的磨损，因此用于破碎岩石的能量取为Q* = 0.54Q。

上述假设的合理性通过以下方式检验：将按式(1)、(3)对不同冲击能量Q*计算得到的αm、tm值，与在相同能量Q* = 0.54Q下岩石接触破碎时试验记录的坑深αл和tm值进行比较。图4给出了在g1 = gст时以αm – (Q*)0.5为坐标绘制的关系式(1)的计算曲线（曲线1），以及试验测得的坑深αл及其线性拟合（曲线2）。

[图4 — 见原文PDF第7页] 砂岩板接触破碎时αm（1）、αл（2）与冲击能量Q*的关系

由图4可见，所得全部试验点均可用关系式(2) αл = k2Q0.5令人满意地拟合。该关系的比例系数（k2 = 0.32·10–3 m/J）与g1 = gст时按式(2)计算的类似系数k1（0.43·10–3 m/J）非常接近。另一方面，岩石接触破碎时按式(3)计算的达到最大力的时间（tm = 0.67 ms）与试验确定的时间（0.90 ms）接近。作者认为，上述情况证实了在将载荷特性表示为函数N = g1α并采用准静态条件下系统刚度系数（g1 = gст）的情况下计算试验中冲击参数的可行性。

表中参数的比较表明，冲击时砂岩板劈裂的能量Qр和比能耗Qр.уд比准静态条件下的相应参数（Aр、Aр.уд）高出10倍以上。这一结果与文献数据一致，其原因既在于冲击时的能量损失，也在于转为动态作用时岩石对塑性变形和破碎的抗力增大。

同时，关于所施加破碎力的比较结果——冲击时约为静态条件下的2倍——与文献[4, 14]的数据相符。正如文献[14]的作者所指出的，文献[10]所得出的在低压入速度下静态与动态加载时力值无显著变化的结论，可解释为这些变化的绝对值较小，被同一试验速度内力值的波动所掩盖。此外，如果认为破碎岩石所需的力在静态和动态条件下相同，那么就无法理解为何这两种条件下的破碎功会相差如此之大（10倍）。而如果承认这些力的大小存在差异，并考虑到本文发现的破碎板材所需压头侵入深度的差异——动态条件下约为静态条件下的2倍——那么上述破碎功（能量）数值的差异就变得可以解释，并可根据这些参数的数值进行计算。

因此，研究结果表明，从能量角度来看，破岩工具对岩石进行相对缓慢作用的破碎方式优于冲击作用。同时，使用冲击系统的优点在于，可以在系统输出端获得比输入端所施加的力大数百乃至数千倍的力[25]，这保证了冲击式机械对岩石的有效破碎。据此可以得出结论：在破碎尺寸相对较小、坚固性不高、无需施加较大力的岩块时，宜采用在准静态条件下工作的设备，例如颚式破碎机；而对于破碎时需要施加很大力的坚硬大块岩石（大块/超限块），则宜采用冲击式设备，例如液压破碎锤。

结论

  1. 在准静态（v ≈ 1 mm/min）和动态（vmax ≈ 2.2 m/s）条件下，将具有半球形钝化部位的压头压入厚度为10 mm和14 mm的砂岩板的试验表明，破岩工具对岩石进行相对缓慢作用时，劈裂过程的功和比能耗比冲击条件下小一个数量级以上。
  2. 假定冲击时砂岩板接触破碎的载荷特性与静态条件下一样，可用N = gα形式的函数描述且系统刚度系数相近，并假定只有约一半（54 %）的冲击能量用于劈裂岩石，计算了不同冲击能量下压头侵入砂岩板的参数——最大侵入深度αm、最大冲击力Nm、板材表面接触破碎及劈裂时的冲击时间tm。
  3. 所计算岩石接触破碎参数值的可靠性由以下两点证实：侵入深度计算值αm与试验记录的崩落坑深度αл相近；冲击时达到最大力的时间的计算值与根据示波图形态试验确定的值相差不大。
  4. 计算与试验相结合的研究表明，冲击时劈裂砂岩板所需的力约为静态加载条件下所需力的2倍，这证实了文献中认为这些参数相互间存在显著差异的数据。
