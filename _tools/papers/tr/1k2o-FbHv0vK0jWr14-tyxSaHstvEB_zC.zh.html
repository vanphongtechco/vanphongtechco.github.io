重复单次冲击下冲击头材料的破坏规律

V.I. Bolobov, Le Thanh Binh

《矿业研究所学报》（Zapiski Gornogo Instituta / Journal of Mining Institute），2018年，第233卷，第525–533页 · 栏目：机电与机械制造 · UDC 620.172.2 · DOI: 10.31897/PMI.2018.5.525

摘要

本文介绍了一项实验研究的方法与结果。该研究考察了自由落体冲击头圆锥形尖端的磨损过程规律：冲击头由38ХМ、У8、Х12МФ钢制成，经过常规热处理并附加冷处理，在接近液压破碎锤钎杆工作条件的情况下，对花岗岩进行多次（最多10000次）单次冲击。为解释相关过程，采用了借助所建立的数学模型计算得到的冲击头与岩石接触面上产生的应力σк。研究确定，多次单次冲击下冲击头的磨损过程分为三个阶段，各阶段之间由临界值σк*、σк**分隔，这两个临界值对应于冲击头材料在该动态条件下所表现出的强度特性。

当冲击次数较少（n ≤ n*）且钝化面尺寸较小时（相互作用第I阶段），σк值超过钢的σк*，钢在接触面上发生局部破坏，表现为冲击头质量的显著损失；当n* < n ≤ n**时（第II阶段），所产生的应力不足以破坏材料，但足以使其发生塑性变形，伴随着金属由接触面中心部分向周边迁移，以及部分变形金属被岩石破坏；当n > n**时（第III阶段），所产生的σк达不到σк**水平，冲击头的质量损失取决于所用钢材抵抗被冲击头从坑中挤出的岩石破碎产物磨削的能力。对所有试验钢种的冲击头进行冷处理均可提高其耐磨性；至停止侵入岩石时，经冷处理的Х12МФ钢冲击头所凿出的坑的总深度是经常规热处理的38ХМ钢冲击头相应指标的四倍。

关键词：多次单次冲击；圆锥形钢制冲击头；冷处理；磨料磨损；金属磨损

引言

采用劈裂和崩落方式的冲击破碎机械广泛应用于矿山巷道掘进、高炉和平炉检修时拆除耐火衬里、冻土和岩石地层开挖、路面破除，以及混凝土、钢筋混凝土和砖砌结构的拆除等领域[7]。此类机械的工作工具通常为圆柱形钎杆，其端部呈锥形或楔形，刃磨角一般为30°至40°[5]。这类机械的破碎过程始于工具侵入具有彼此相距较近的自由面的岩体，侵入深度须足以使因侵入而产生的拉应力和剪应力从岩体上剥离出所需尺寸的岩块。机械的工作能力取决于其将冲击工具侵入到给定深度的能力，而生产率指标则为侵入速度[5]。

随着工具的使用，由于其材料的冲击磨料磨损，钎杆尖端部分的钝化面尺寸不断增大。这导致冲击时工具与岩石的接触面积增大，冲击破碎强度降低。结果，从某一时刻起，钎杆侵入岩石的过程实际上停止，若要恢复则需更换或重新刃磨钎杆。例如，DAEMO B180液压破碎锤的使用经验表明，对该机械而言，当钎杆尖端部分磨损约50 %时即达到这一时刻，因此一根钎杆仅可重磨4–5次。鉴于更换大质量钎杆及其重磨均为非常费工的作业，研究提高液压破碎锤钎杆材料抗冲击磨料磨损能力的方法，从而延长钎杆在重磨前的使用时间，是一项迫切的任务。

关于冲击工具，特别是液压破碎锤破碎岩石的问题，已有大量研究。基于力学定律和经典赫兹理论，建立了经典冲击理论和波动冲击理论，将冲击头与被破碎材料相互作用的能量、力和时间与冲击头侵入岩石的深度联系起来。而与冲击头材料磨损机理有关的问题，以及其尖端钝化面尺寸（随时间并取决于材料耐磨性而变化）对液压破碎锤生产率的影响，尚未得到充分研究。

本文在接近劈裂和崩落式冲击破碎机械钎杆工作条件的情况下，研究了自由落体冲击头对岩石进行单次冲击时其材料的磨损过程规律。

实验方法

研究对象为长L = 25 mm的冲击头，具有圆柱段（D = 6 mm，l1 = 13.8 mm）和顶角β = 30°、长l2 = 11.2 mm的圆锥形尖端，由38ХМ、У8、Х12МФ钢制成——这些钢均为液压破碎锤钎杆材料，在强度和耐磨性方面各不相同。一部分钢进行常规热处理（ТТО）——自800–1000 °C油淬并于200 °C回火，即钎杆制造厂所采用的工艺；另一部分则附加冷处理[4]（在–75 °C下保持5 h），这是广泛用于改善工具钢耐磨性的一道工序[8, 10, 11, 13]。采用Zwick/Roell ZHU万能硬度计测定热处理后冲击头材料所达到的硬度。

试验在结构与文献[2]所述装置相近的装置（图1）上进行。

由上述某一牌号钢制成的冲击头2，经分析天平（±0.0001 g）称重后，以竖直姿态固定在大质量落锤3（M = 2.8 kg）中。冲击头下方放置岩石试块1——普氏（M.M. Protodyakonov）坚固性系数为6.2的花岗岩，其集合体硬度约450 HV，组成矿物的硬度可达1200 HV（石英），高于所用冲击头材料的硬度。

使带有冲击头的落锤从一定高度（H = 42 mm）落下，用冲击头尖端对试块表面的不同点进行一系列n次冲击，每次冲击不同的点。由M和H计算得到的带冲击头落锤的动能A0和冲击前速度v0分别为1.16 J和0.91 m/s。每次冲击后，对冲击头重新称重并测量L（测量精度±0.01 mm），确定其尖端的质量损失Δm和长度减少量Δl，并根据Δl结合β计算所形成钝化面的直径d。当冲击次数超过40次时，Δm和Δl按间隔n（10至100次）测定，并以该间隔内各量的总值除以间隔内冲击次数之商计算。分析岩石中崩落坑的形貌并测量其深度h（测量精度0.01 mm）。改变冲击头材料，对每种材料建立Δl、d、h与冲击次数n的关系曲线。

实验结果

观察表明，冲击花岗岩的过程伴随着冲击头不大的（数毫米）回弹。第一次冲击的结果是在冲击头尖端出现圆形钝化面，其直径d随冲击次数的增加而增大。

花岗岩的破坏表现为颗粒和粉尘状碎屑从破坏区飞出，形成形状接近冲击头侵入部分轮廓但直径更大的崩落坑。在坑底发现由粉末状破碎产物构成的压实核，其颜色（白色）与岩石其余部分不同。

研究确定，随着冲击次数增加，Δl和h值单调减小（图2）。而且，所分析钢种的Δl = f(n)曲线在图中的相对排列顺序与同一材料的h = f(n)曲线的排列顺序相反。所得Δm = f(n)关系的典型形式如图3所示。由图3曲线形态可以推断，对于所有被分析的材料，冲击头质量损失Δm随冲击次数n的变化过程均具有三个阶段。第一阶段（第I阶段）包括最初几次冲击，直至某一临界冲击次数n* = 8–10（各钢种不同），此阶段Δm值以十分之一毫克计，并随每次后续冲击以明显速率（0.3–0.4 mg/次）下降。第II阶段始于n ≥ n*并持续至第二临界值n** = 3600–5400，此阶段Δm仅为百分之几毫克，且其随n增大而下降的速率急剧减慢。第III阶段（n > n**）持续至系列试验结束，质量损失Δm变得与冲击次数无关。对每种钢测定的该Δm值被视为材料在磨损过程稳定阶段的冲击磨料磨损速率K，而K的倒数I则被视为该冲击头材料的抗冲击磨料磨损能力（耐磨性）。

为解释冲击头各磨损阶段所发生的过程，采用了借助所建立的数学模型计算得到的冲击头与岩石接触面上所产生应力大小的数据。

实验条件下岩石冲击破碎过程的数学模型

建立模型时，基于这样的前提：冲击头与落锤构成长度相对较小的结构（LΣ = 340 mm）。认为可以忽略波动过程对冲击参数的影响，冲击头与被破碎材料的相互作用过程可以用经典二元冲击系统的方程来描述[5]。计算结果表明，满足这些方程的适用条件：

tm ≥ 3T，

式中tm为冲击时间，tm = 0.6–1.4 ms；T为冲击头与落锤的固有振动周期，T = 0.13 ms。

根据文献[5]关于现有破碎载荷特性类型的结论，并结合我们对冲击过程的观察，假定在实验条件下冲击头侵入岩石具有三个基本阶段：

  • 岩石弹性变形，直至其与冲击头接触面积上的应力达到σк，此时接触面下方的岩石发生爆炸式破坏；
  • 冲击头穿过岩石破碎核推进，将部分产物挤出坑外，并压实剩余产物，但未到达破坏区底部；
  • 冲击头被压实破碎产物的残余弹性力弹回。

在这种情况下，岩石阻力N与变形α的关系（图4）对应于V型载荷特性[5]，由三个力函数组成：接触面下岩石弹性变形时的加载N1、冲击头侵入岩石破碎产物时的加载N2以及卸载N3，每个函数各有其刚度（g1、g2、g3）。此时，函数N1、N2、N3与接触面积不变的物体侵入情形一样，均为线性。图4中图形的面积为加载功Aн，阴影部分面积为破碎所消耗的功Aр。

对于这种载荷特性，岩石最大阻力Nm和侵入量αвн以及冲击时间tm为[5]：

Nm = Nр · √(1 − g2/g1 + 2Aнg2/Nр2)；
αвн = αm − Nm/g3 = Nр · (1/g2 − 1/g1) · (√(1 − g2/g1 + 2Aнg2/Nр2) − 1)；
tm = √(M/g2) · arctg √(2Aнg2/Nр2)，

式中M为下落物体质量；Nр为岩石接触破坏力，

Nр = fкσкр，

fк = πd2/4为接触面积；σкр为接触处的应力，在该应力下冲击时岩石中产生的拉应力和剪应力σр导致接触面下方岩石的爆炸式破坏。

[图4 — 见原始PDF第4页] 计算冲击参数时所采用的系统载荷特性形式

计算中采用的假设：

  • 临界接触应力σкр可取岩石的动态硬度值（花岗岩为1305 MPa[9]）；
  • 对于确定系统的接触刚度g1，与直径为d的圆形接触面一样，文献[5]中的公式适用：
    g1 = 2Eпd / [3(1 − μп2)]，
    其中花岗岩的弹性模量Eп = 50 GPa，泊松比μп = 0.2[5]；
  • 类比刚度比g2/g1和g3/g1（可通过分析文献[6]给出的脆性岩石接触破坏实验力特性确定），在本文情况下刚度g2可取0.16 g1，g3可取g1；
  • 冲击头动能A0中仅约一半消耗于岩石的弹性变形和破坏（花岗岩为58.6 %[5]），其余能量消耗于向周围环境的热损失、冲击头的弹性和塑性变形以及其接触表面的磨损[9]，因此取Aн = 0.586 A0 = 0.68 J。

由表1数据可知，所测得的钢的抗冲击磨料磨损能力总体上与其硬度及强度指标σв、σт相关，随这些参数的增大而提高。其中，耐磨性最低的是经常规热处理的38ХМ钢，最高的是经冷处理的Х12МФ钢，高出2.7倍。可以注意到，冷处理同样提高了所有其他钢的耐磨性（提高11 %至26 %）。

可以看出，随着钢的强度和耐磨性提高，对应于相互作用阶段转变的接触应力σк**、σк*值也随之增大。同时，σк*与σв之间以及σк**与σт之间存在一定的相关性：前者（σк*、σк**）比后者大致大相同的倍数。根据存在三个特征相互作用阶段（见图3）以及上述比例对所有钢均成立这一事实，可以推测，通过计算–实验方法确定的接触应力临界值σк*、σк**对应于与接触面相邻的该冲击头材料层中的应力，从该应力起材料在动态条件下能够发生破坏（σк*）或塑性变形（σк**）。在试样静态拉伸条件下，应力σк*的对应参数为“真实断裂应力Sк”，应力σк**的对应参数为材料的屈服强度σт，其数值小于钢相应的动态特性值。可以指出，文献[2, 6]针对工业纯铁和中碳合金钢描述了大致相同的情况：高应变速率下测得的屈服强度σт（高达1.1倍）和抗拉强度σв（高达2倍）高于试样静态压缩和拉伸时测得的值。

当钝化面直径较小时（n < n*，d < d*，第I阶段），冲击时产生的接触应力σк超过该钢的真实动态断裂应力σк*，接触面上产生裂纹，裂纹扩展导致大体积金属剥落，表现为冲击头质量的明显损失。当直径较大时（d* < d ≤ d**，n* < n ≤ n**，第II阶段），所产生的应力不足以破坏冲击头材料，但足以使其发生塑性变形，伴随金属由接触面中心部分向周边迁移。根据该阶段冲击头存在明显质量损失这一事实，可以推断，相当一部分变形并被裂纹削弱的金属体积被运动的岩石破碎产物带走。

关于冲击头尖端在相互作用初期阶段发生破坏和显著塑性变形的结论，得到了作者专门进行的试验结果的支持：在该试验中，冲击头不是冲击磨料，而是冲击由更硬且不会被破坏的材料制成的光滑平板。由图6所示的该实验结果可以推断，在冲击次数较少时，冲击头尖端部分发生崩落，接触面上出现由中心指向周边的变形金属波纹。图6中可以看到边缘效应的表现——接触面周边区域的剥落。

在相互作用初期阶段，冲击次数n越多、冲击头钝化面越大，所产生的接触应力σк及其超出所用钢的σк*或σк**的幅度就越小，相应地接触面上发生破坏或变形的金属区域就越薄，因而Δm值也越小。

[图6 — 见原始PDF第7页] У8钢冲击头钝化面形貌：第I相互作用阶段冲击硬质金属基板后（a）及第III阶段冲击花岗岩后（b）

当n ≥ n**、d ≥ d**（第III阶段）时，所产生的接触应力σк达不到σк**水平，冲击头尖端不发生塑性变形。在转为冲击岩石时，该表面上出现平行划痕，说明此时接触面金属受到运动磨粒的作用。划擦的结果是金属质量损失远小于第I、II阶段，其大小取决于制造冲击头所用钢的抗磨料磨损能力，而后者又取决于钢的硬度和组织特点[3]。需要指出的是，接触面上除划痕外还存在凹坑，这可能说明冲击时冲击头材料除受运动磨粒磨损外，还受到固定磨粒的压入[2]，这一现象发生在坑内残留岩石破碎产物的压实阶段。

在冲击头磨损的稳定（第三）阶段，破碎岩石时消耗于冲击头磨损的能量份额，是根据所测得的材料磨损速率K和相应钢的临界应力σк*进行估算的。此时假定，由于在本文情况下材料磨损主要是由磨料对其表面的破坏（划擦）引起的，该过程的比功Aуд可按文献[1]针对试样拉伸时金属破坏所提出的公式估算：

Aуд = Sк/ρ，

式中Sк为金属的真实断裂应力，根据作者上述假设，在动态条件下等于表1中具体钢的σк*；ρ为密度，所有钢均取ρ = 7.85·103 kg/m3。

于是，每次冲击消耗于冲击头材料磨损的功为：

Aме = K Aуд = K σк*/ρ，

而金属磨损所耗功Aме在冲击能量A0中所占比例为：

Aме% = Aме/A0 = K σк*/(A0 ρ)。

在稳定相互作用第III阶段，冲击头单次侵入花岗岩过程中消耗于其弹性变形的功Aупр，按d = d**时岩石最大阻力Nm与冲击头弹性变形时圆柱段Δl1упр和圆锥段Δl2упр长度总减少量ΔlΣупр的乘积计算，其中

Δl1упр = Nml1/(S1E)，

式中S1为圆柱段截面积；E为杨氏模量，所有钢均取E = 200·109 MPa。

为确定底面分别等于冲击头圆柱段面积和钝化面面积的截头圆锥的Δl2упр，将其沿高度变化的横截面积Si用距锥顶的距离x和刃磨角β = 30°表示：

Si = πx2tg2(β/2)

并求解锥体高度因弹性变形而产生的相对变化作为x函数的微分方程：

dl/dx = σ/E = Nm / (Eπx2tg2(β/2))，

将其沿坐标x从锥顶至钝化面x1（d**时的Δl）和至底面x2（l2）积分，最终方程形式为：

Δl2упр = [Nm / (Eπ tg2(β/2))] · ∫x1x2 (1/x2) dx = −[Nm / (Eπ tg2(β/2))] · (1/x)|x1x2 = [Nm / (Eπ tg2(β/2))] · (1/x1 − 1/x2)。

相应地，Aупр%等于Aупр/A0。

假定表2中所测得的钢的冲击磨料磨损速率K在后续冲击中一直保持不变，直至钝化面直径达到3.55 mm（此时不再形成坑），计算了各钢种冲击头至该时刻的冲击次数n***及所得坑的总深度hΣ。

由表2可以推断，冲击头单次侵入花岗岩过程中消耗于冲击头材料破坏的功Aме%约占冲击能量的0.1 %。同时，随着制造冲击头所用钢的耐磨性提高，Aме%所占份额减小。冲击头弹性变形功Aупр%占冲击能量的百分之几，并与Aме%一样随冲击头材料耐磨性的提高而减小。例如，对于强度最低的38ХМ钢，该值为9.8 %（d** = 2.11 mm，Nm = 5.80 kN，Δl1упр = 0.0182 mm，Δl = 3.94 mm，Δl2упр = 0.0211 mm），而对于强度最高的钢（Х12МФх）为6.6 %（d** = 1.62 mm，Nm = 4.28 kN，Δl1упр = 0.0127 mm，Δl = 3.02 mm，Δl2упр = 0.0229 mm）。计算表明，随着冲击次数进一步增加（超过n**）以及钝化面直径相应增大（超过d**），Aупр%所占份额增大，对所有钢而言，至冲击头尖端完全钝化时达到约36 %。

由表2可知，至冲击头停止侵入岩石时，经冷处理的Х12МФх钢冲击头凿出的坑的总深度hΣ是38ХМ钢冲击头相应指标的四倍，这是由于Х12МФх钢冲击头的耐磨性显著更高。

结论

综上，计算和实验表明，圆锥形钢制冲击头单次冲击花岗岩时的磨损过程具有三个相互作用阶段，每个阶段由冲击头材料在动态条件下所表现的强度特性σ*、σ**与冲击头–岩石接触面上产生的、随冲击次数n增加而降低的应力σк之间的关系决定。在最后的稳定相互作用阶段，冲击头的质量损失随冲击次数增加几乎不变，并取决于所用钢的耐磨性；因此，对所分析的钢种而言，冲击头尖端完全钝化前的冲击次数和所得坑的总深度分别相差2.6倍和4.0倍。
