保证煤炭高效装入工作面输送机的采煤机螺旋滚筒几何参数与工况参数的论证

V.V. Gabov, Nguyen Khac Linh, Nguyen Van Xuan, Le Thanh Binh, D.A. Zadkov

《煤炭》（Уголь）杂志，2018年第2期，第36–39页

摘要

本文分析了煤矿综采工作面中采煤机螺旋滚筒将煤从破碎区卸出并装入工作面输送机的过程。从减少煤的附加破碎和降低单位能耗的角度，探讨了提高工作面输送机装煤效率的可能途径，这可以通过增大装载窗口的截面积和输送机上装载区的容积来实现。

关键词：井工煤炭开采，综采工作面，采煤机，螺旋滚筒，工作面输送机，煤，装载，破碎，效率。

引言

在综合机械化采煤成套设备中，采煤机螺旋滚筒承担着主要功能——将煤从煤体上分离并装入工作面输送机。螺旋滚筒具有工艺性好、结构紧凑、构造简单、可靠耐用等特点[1, 2, 3]。然而，沿采煤机运行方向处于后方的螺旋滚筒存在清底效果不佳的问题，这会导致采煤机生产能力下降、单位能耗增加以及煤在装入输送机时发生附加破碎。造成这种状况的主要原因是装载窗口尺寸受限以及滚筒与输送机之间的距离较大[1, 4, 5]。问题在于，目前尚缺乏相应的技术方案和经过验证的方法，用以确定采煤机螺旋滚筒的结构和参数，以及在满足落煤装入工作面输送机过程效率指标要求值的前提下，使其与输送机和装煤挡板一起合理布置于工作面空间之中。

采煤机螺旋滚筒参数的论证

研究装载过程并论证能够提高装载—运输过程效率的采煤机螺旋滚筒参数，是一项具有现实意义的科学任务。

在工作空间充满系数相对较小（不超过0.3—0.4）的水平和小倾角螺旋装载与输送机构中，散状物料的移动伴随着在每片叶片前方形成拖曳体。拖曳体内部发生由方向各异的重力、惯性力和摩擦力引起的循环过程[6, 7]。这导致了螺旋输送机的主要缺点：物料移动能耗增加以及物料的附加二次破碎（通常是不希望出现的）。当拖曳体沿滚筒旋转方向达到某一临界偏转角θк（图1）时，被输送物料在拖曳体内的循环强度急剧增大，此时形成了物料沿其自由表面上阻力最小的路线崩落的条件。

[图1 — 见原始PDF第2页] 图1. 螺旋滚筒中物料的移动

物料的偏转角可按下式确定[6]：

θк = arcsin ( (tg β + f2Rω2 / (g cos β)) / √[ (2πR / S) · (1 − f1√(ctg2γ + (S / 2πR)2 + 1) + f2 ctg γ) + f22 ] ) + arctg ( f2 / [ (2πR / S) · (1 − f1√(ctg2γ + (S / 2πR)2 + 1) + f2 ctg γ) ] ), (1)

式中：γ——滚筒轴线与水平面的倾角；β——滚筒轴线与水平面的倾角；R——导向面半径，m；S——滚筒螺旋线螺距，m；f1——物料与限制料流的表面（煤壁面、挡板、导向管、钻孔）之间的摩擦系数；f2——物料在叶片上运动的摩擦系数；ω——滚筒转速，1/s；g——重力加速度，m/s2。

[图2 — 见原始PDF第2页] 图2. 螺旋滚筒落煤生产能力Qтр和循环煤量Qц随滚筒截面充满系数的变化关系[1]

M.S.萨福欣、I.M.皮特鲍姆、V.N.韦尔纳等人的研究[5, 6, 8]阐述了滚筒几何参数和工况参数以及被输送物料性质对θК值的影响程度和特点。根据上述关系，可以判断各种因素沿相同工况线对物料在滚筒中运动偏转角影响的等效性。物料偏转角θК越大，循环强度kц越高。

滚筒截面的充满程度取决于滚筒直径与其轮毂直径之差。正如文献[1, 6]所指出的，滚筒充满程度的增加会导致循环系数增大。充满系数ψн和循环强度kц的数值在很大程度上取决于采煤机的牵引速度和滚筒直径。此外，循环强度还取决于滚筒的抛掷能力，抛掷能力随螺旋升角的增大而增大，因为抛掷物料的力分量pr和pθ（见图1）随螺旋升角αi的增大而增大。该曲线在αi = 18—23°时出现最小值[1]。

装载过程中物料的循环强度可用循环系数kц来评价，适用于充满系数ψн的任意值：

kц = Qц / (Qтр − Qц), (2)

式中：Qтр——螺旋滚筒的落煤生产能力；Qц——滚筒的循环物料量（图2）。

线1（见图2）表示滚筒落煤生产能力的变化关系，线2表示循环物料的煤量。ψн max值确定了充满系数的界限，超过该临界值将导致循环物料量增加。

根据采煤机后滚筒旋转方向的不同，落煤在滚筒空间内以特定的方式分布（图3）。

当滚筒相对于采煤机牵引速度顺向旋转（由底板向顶板）时（见图3a），大部分落煤向下落并被滚筒送入工作面输送机，仍停留在靠近煤壁的工作空间内。在这种情况下，煤的破碎程度降低。角φ（见图3）取决于煤与滚筒叶片及轮毂表面之间的摩擦系数，并与物料位置偏转角θК成正比。随着滚筒生产能力的提高，其出口处的充满程度增加（见图3，位置I、II）。

当滚筒相对于牵引速度逆向旋转（由顶板向底板）时（见图2b），所装煤的大部分位于装煤挡板一侧，与煤层底板形成角φ。随着采煤机牵引速度的提高，滚筒内的煤流增大。在滚筒转速、螺旋头数和导程不变的情况下，料流速度将保持不变。可能出现物料滚落到滚筒筒体上并被抛入清底板区域的时刻。在此处，物料或者在没有清底板时留在煤层底板上（图3c），使未装载煤层的高度H0增加[1]；或者被移动的挡板收集，由滚筒送入输送机，同时部分被卷入滚筒工作空间区域，形成循环物料流。

[图3 — 见原始PDF第3页] 图3. 后滚筒工作空间内落煤分布示意图

图3表明，煤流并不是在滚筒整个截面上卸出的。其卸载区取决于滚筒的几何参数和工况参数。在实际结构中，卸载区内装载窗口的面积受到滚筒轮毂直径、工作面输送机槽帮高度以及滚筒减速器壳体尺寸的限制。窗口尺寸受限增大了煤流运动的阻力，从而导致滚筒充满系数增大。

在逆向旋转（见图3a、c）且牵引速度提高时，位于滚筒工作空间内的煤流面积增大[10, 11, 12]。煤流高度的增加导致螺旋滚筒工作空间内煤的循环加剧。详细考察可知，就其物理本质而言，整个装载过程可以表示为在相邻区域I、II、III中进行的三个不同过程（图4）。

[图4 — 见原始PDF第3页] 图4. 滚筒截面充满系数沿截深Bз的分布

滚筒内物料的充满系数和循环强度沿截深Bз变化（见图4）。在角区I，从煤体上分离的煤流较小，尚未形成拖曳体，煤的抛掷、循环和破碎加剧。在区域II（截齿破碎煤体区），滚筒充满系数增大，形成拖曳体。在区域III（向输送机卸煤区），由于装载窗口通过能力有限造成料流壅塞，滚筒充满系数增大。

当滚筒顺向旋转时，料流位于底板与挡板之间（见图3b）。在各滚筒落煤生产能力相同的条件下，这种情况下的料流高度低于逆向运动时的料流高度，同时循环强度降低。但料流面积的增大会使其流速降低。

结论

根据上述内容，可以得出以下结论：

  • 煤炭装入输送机的过程尚未得到充分研究，较大的能量消耗、伴随产生的煤炭破碎和粉尘生成对开采过程的效率产生不利影响；
  • 所研究的螺旋滚筒将煤移送至输送机的过程应视为由三个相互关联的过程组成：从角区卸煤；叶片沿滚筒在截深范围内输送煤；以及将散状物料经装载窗口挤压送入输送机；
  • 需要研究滚筒充满系数和装载窗口面积大小对煤循环强度和装载过程效率的影响；
  • 需要寻找和开发能够降低煤的循环强度和破碎程度、并通过扩大装载窗口减小煤运动阻力的技术方案。
