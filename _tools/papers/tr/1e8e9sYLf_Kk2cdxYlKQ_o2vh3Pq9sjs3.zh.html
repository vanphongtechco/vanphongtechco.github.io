考虑钎杆钝化程度的液压破碎锤冲击破岩建模

V. I. Bolobov, S. A. Chupin, B. Le-Thanh

Eurasian Mining（欧亚矿业），2022年，第1期，第72–75页 · DOI: 10.17580/em.2022.01.15

摘要

岩石和人工复合材料的破碎可采用多种方式进行，其中最常用的方法之一是冲击破碎。本研究以JCB HM380液压破碎锤的锥形钎杆作为冲击工具。岩石破碎的试验研究在一种人工复合材料——混凝土上进行，以钎杆冲入混凝土的深度作为试验参数。模型以V. B. Sokolinsky教授的模型为基础。本文建立的模型考虑了单次冲击和多次冲击中工具的钝化程度。由于钎杆–花岗岩接触刚度较高（相对于破碎锤活塞–钎杆接触刚度），系统被视为二元系统。由于钎杆长度较短，忽略了钎杆中的波动过程。利用所建立的数学模型，对钎杆每次冲击时侵入岩石的深度进行了理论计算，并与试验数据进行了比较。破碎试验同样采用JCB HM380破碎锤和混凝土，侵入深度通过对过程录像进行逐帧分析确定。研究发现，无论单次冲击还是多次冲击，钎杆钝化都会使岩石对钎杆侵入的阻力单调增加，而工具侵入深度和冲击时间则减小（与工具初始状态相比，分别减少28%和20%）。

关键词：液压破碎锤，钎杆，钝化程度，侵入，花岗岩，数学模型，冲击参数

引言

矿产开采业是包括俄罗斯在内的许多国家经济中重要的财政收入来源部门[1]。没有先进的开采方法，就无法增加财政收入。矿产开采是一个复杂的过程，需要采用各种方法和机械来实现[2–6]。作为矿产开采中应用最广泛的方法，爆破的效率在很大程度上取决于钻孔设备和工具[4, 7]。另一方面，某些作业只能采用冲击方法（破碎大块、清除浮石等）。与岩石直接相互作用的冲击工具磨损很快。工具的这种劣化降低了生产率，并增加了购置新工具的费用。目前正在开展广泛的研究，以寻求通过改进设计、采用新材料或应用创新加工技术来延长冲击工具使用寿命的途径[8–17]。

俄罗斯和国外学者已对冲击破岩的理论框架进行了描述[18–33]。冲击工具侵入岩石的过程已被数学建模，破岩能耗和冲击机械生产能力也得到了估算[34–36]。然而，冲击工具钝化对冲击效率的影响尚未得到应有的重视。本文试图填补这一空白。

冲击工具侵入岩石及含岩复合材料的数学模型采用了Sokolinsky教授的研究成果[37]。

建模以液压破碎锤冲击花岗岩（σcom ~200 MPa）为研究案例。液压破碎锤的破岩工具为钎杆。液压破碎锤的技术参数如下：

型号JCB HM380
规格中型
破岩工具钎杆
冲击能量A0，J981
冲击频率ν，s-15–10
冲击时钎杆速度v0，m/s6.3

液压破碎锤的冲击组件由活塞（其端面为半径Rp = 0.5 m的半球形）和刃部为钝化锥形的圆柱形钎杆组成（质量Mpick = 25 kg；长度Lpick = 800 mm；圆柱部分半径Rcyl = 37.5 mm；锥高100 mm；锥角30°；锥体钝头为半球形）。

对破碎花岗岩大块后的钎杆进行检查表明，钎杆的锥形刃部因磨损而变为半径rsp0 = 13 mm的半球形（半球开始形成）。随着磨损增加，钎杆长度缩短，锥体钝化半径增大至rcr = 37.5 mm。工具钝化程度Stool由下式确定：

Stool = rsp/Rcyl,   (1)

式中rsp为测量时锥体球面半径，mm；Rcyl为钎杆圆柱部分半径，mm。在半球开始形成时，Stool0 = 0.35（rsp0 = 13 mm时），在工具临界状态下，Stoolcr = 1（rcr = 37.5 mm时）。

基于文献[37]的接触刚度分析采用了能量经钎杆从破碎锤传递到岩石的传递系数：

ε = 1/(1 + e1/e0),

式中e1为钎杆–岩石接触刚度，N/m3/2；e0为活塞–钎杆接触刚度，N/m3/2：

e1 = 4√rc / [3((1 − μ2tool)/Etool + (1 − μ2tool)/Erock)],   (3)
e0 = 2Ep√Rp / 3,   (4)

式中Erock为岩石弹性模量，GPa（50 GPa）；Etool为工具材料弹性模量，GPa（200 GPa）；Ep为活塞材料弹性模量，GPa（50 GPa）；μrock为岩石泊松比（0.2）；μtool为工具材料泊松比（0.3）。

在不同工具钝化程度（rsp）下，能量传递系数的计算值接近1（0.9–0.94）。这使得可以将活塞–锤体中间系统从计算中去除，仅分析钎杆–破碎岩石二元系统。

根据Sokolinsky理论[37]，该二元系统的另一个条件是破碎锤中不存在波动过程。当碰撞持续时间大于或等于碰撞体自由振动周期的三倍时，该条件成立。对于JCB HM380破碎锤的短钎杆，碰撞持续时间为1 ms，而自由振动周期为0.3 ms。

根据文献[37]，破岩工具侵入岩石分为三个阶段：

  1. 在与工具接触处达到临界应力之前，岩石表现出弹性性质。随着应力增大，接触处岩石发生类似爆炸的破坏。
  2. 工具进一步侵入，克服破坏核并将破碎岩屑挤出。其余破碎岩石在孔底被压实。
  3. 在被压实的破碎岩屑残余弹性作用下，工具被反推回来。

岩石阻力F取决于工具侵入深度h（岩石变形），根据文献[37]，在半球形接触面的情况下，该阻力是非线性的，由三种载荷组成：F1——接触处弹性变形；F2——工具侵入破碎岩石；F3——工具回弹。每种载荷都有其自身的刚度。

由文献[37]可知，在这种加载条件下，最大阻力Fmax、侵入深度apen、冲击时间tmax以及接触处最大应力σcr由下列各式给出：

Fmax = Frock + e2(amax − arock)3/2,   (5)
Frock = (9π3/2) · ((1 − μ2tool)/Etool + (1 − μ2rock)/Erock)2 · r2sph σ3cr,   (6)

式中Frock为接触处破坏力；arock为岩石弹性变形；

arock = (Frock/e1)2/3,   (7)
e1 = 4√rsph / [3((1 − μ2tool)/Etool + (1 − μ2rock)/Erock)],   (8)
apen = amax − (Fmax/e3)2/3,   (9)

式中amax由下列方程求得：

(2/5)e1e5/2rock + Frock(amax − arock) + (2/5)e2(amax − arock)5/2 = Al,   (10)
tmax = mv0/Fmax,   (11)
σcr = Fmax/fh,   (12)

式中m为工具质量；fh为硬度系数。

改变刚度e1和e2表达式中的rsp值，即可评估工具钝化程度对冲击效率的影响。

单次冲击计算

利用式（5）–（12），将工具钝化程度Stool与最大阻力Fmax、侵入深度apen、冲击时间tmax以及接触处最大应力σcr联系起来。

建模时取花岗岩的临界应力σcr等于其动态硬度σd = 1300 MPa[38]。选取该值是为了符合文献[39]的结论，即大多数岩石的强度特性在从静载转为动载时会增大。刚度值按文献[39]选取：e2 = 0.15e1，e3 = e1。

约一半的动能E0用于破碎岩石（Erock），其余能量用于岩石发热和工具的弹性变形。

求解（5）–（12）后绘制的关系曲线（图1）表明，在动量不变的情况下，岩石对工具侵入的最大阻力（曲线1）随工具钝化而单调增大。冲击时间（曲线3）亦是如此。与此同时，侵入深度值减小（曲线2）。花岗岩中的接触应力几乎保持不变（约686 MPa）。

多次冲击计算

在露天矿使用JCB HM380液压破碎锤进行的破岩试验表明，在同一点连续冲击约30次后岩石才被破碎，且工具侵入深度随每次后续冲击而减小。模型中考虑了这一现象。

摩擦增大使每次冲击时岩石对侵入的阻力Fmaxi与侵入深度apeni成比例增加，从而导致每次后续冲击的apeni减小。所得总加载特性如图2所示。

在循环中，岩石对钎杆侵入的阻力随每次冲击而增大（见图3），冲击时间则减小。到第30次冲击时，冲击时间比第一次冲击时缩短一半。工具钝化程度从0.35增至1.0（见图4）时，每个循环在岩石中的总侵入深度Σapeni减少28%，总最大时间Σtmaxi缩短20%。

结论

通过本研究，建立了破岩工具侵入岩石的数学模型。研究发现，钎杆的临界钝化使岩石侵入阻力增加至2倍，同时侵入深度减小28%，最大冲击时间减小20%。试验数据与计算结果吻合。
