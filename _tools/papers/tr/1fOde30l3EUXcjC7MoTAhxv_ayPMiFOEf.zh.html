液压破碎锤钎杆工作寿命与其材料耐磨性的关系

V.I. Bolobov, Le Thanh Binh, S.A. Chupin, V.A. Plashchinsky

《矿业信息分析通报》（GIAB / MIAB. Mining Informational and Analytical Bulletin），2020年，第5期，第68–79页 · DOI: 10.25018/0236-1493-2020-5-0-68-79 · UDC 620.172.2

摘要

本文给出了冲击能量对三种牌号工具钢制成的圆锥形钎杆模型工具在与花岗岩块冲击相互作用时冲击–磨料磨损强度影响的试验结果。一部分工具采用钎杆制造厂通行的标准热处理，另一部分则附加冷处理或深冷处理。为论证试验数据可推广至现场条件，设定了试验工作参数，使试验条件与液压破碎锤钎杆的工作条件相似。为实现这种相似，试验中模型工具与岩石之间的接触应力水平与钎杆冲击侵入时相同。建立了模型工具冲击–磨料磨损强度与冲击能量之间的关系，并据此计算了JCB HM380液压破碎锤钎杆破碎花岗岩块时的磨损强度。以钎杆尖端完全磨损前所承受的冲击次数作为钎杆的工作寿命进行了评估。通过比较由所研究钢种制成并经上述热处理的钎杆的工作寿命，得出结论：在液压破碎锤钎杆制造工艺中引入冷处理和深冷处理工序是合理的。

关键词：液压破碎锤钎杆；冲击作用；冲击能量；花岗岩；冲击–磨料磨损；接触应力；尖端钝化；冷处理；深冷处理；钎杆工作寿命

引言

关于冲击工具与被破碎岩石的相互作用以及提高其耐磨性的方法，已有大量研究工作，例如文献[1–14]。

作者在文献[15]中给出了圆锥形模型工具多次冲击侵入花岗岩块后其钝化面磨损的试验结果。研究发现，工具质量损失与冲击次数之间的关系可用Δm = An–B形式的反幂函数描述，其中A和B为取决于工具材料及热处理方式的系数；磨损过程分为3个阶段，各阶段金属质量损失量及其随冲击次数增加而下降的速率各不相同。利用所建立的数学模型表明，磨损由一个阶段向另一阶段的转变取决于工具与岩石接触处达到的应力与其材料在动态条件下表现出的强度极限和屈服极限之间的关系。在持续时间最长的最终磨损阶段，每次冲击的金属质量损失基本不随冲击次数变化，可作为该钢制工具冲击–磨料磨损强度的指标Kм［mg/次冲击］。

本文建立了Kм值［15］与模型工具冲击能量Aм的关系，并据此评估液压破碎锤钎杆的冲击–磨料磨损强度Kп及其至尖端完全磨损的工作寿命（冲击次数）。

试验方法

试验装置的外观及示意图见图1。

模型工具2（见图1）为圆锥形钎杆，顶端锥角β = 30°，圆柱段半径rм = 4 mm（满足相似准则所需），在分析天平（±0.1 mg）上称重后固定于装置的大质量冲击头3中。

[图2 — 见原文PDF第6页] 模型工具进行一系列冲击后花岗岩块的表面

工具下方放置取自维堡岩体的圆柱形花岗岩岩芯试样1，其按M.M.普罗托季亚科诺夫分级的坚固性系数f = 13，单轴抗压强度σсж ~200 MPa。工具2与冲击头3一起从设定高度（hм = 42 mm）自由下落，以尖端冲击试样表面。由h计算得到的工具冲击前速度为0.91 m/s。用同一模型工具对试样1表面进行n次系列冲击，每次后续冲击点偏移距离≥ 3dл，其中dл为冲击坑直径（图2）。

每次冲击后测量模型工具的质量，以确定冲击引起的质量损失Δm。当冲击次数较多（超过40次）时，按冲击区间（n = 10–100）确定每次冲击的Δm，即区间内n次冲击的函数累计值除以区间冲击次数n。通过改变冲击头3的质量（2.8、4.2、5.6和7.0 kg），研究了冲击动能（Aм = 1.16、1.74、2.32和2.90 J）对工具质量损失Δm与冲击次数n关系形式的影响。

模型工具材料选用38ХМ、У8А和Х12МФ钢。第一种是国内（俄罗斯）及国外（AISI P20钢）钎杆的典型材料；第二种是主动式挖掘机铲斗冲击齿的材料，在试验中表现令人满意［16］；第三种是淬火状态下具有高硬度和高韧性的材料，已作为防止斗齿磨损的堆焊层通过现场试验［16］。

上述钢制工具一部分采用钎杆制造厂通行的标准热处理（ТТО）——800–1000 °C油淬后200 °C回火；另一部分附加冷处理（淬火后在零下75 °C保持5 h）或深冷处理（淬火后在零下196 °C液氮中保持20 h），这些工序被广泛用于提高金属切削刀具的耐磨性［17–26］。

模型工具与液压破碎锤钎杆侵入岩石过程相似性的论证

为论证在实验室条件下用模型工具获得的试验数据可推广至现场条件，设定了试验工作参数，使试验条件与液压破碎锤钎杆的工作条件相似。

根据K.I.伊万诺夫［27］的结论，认为要保证模型冲击工具与钎杆侵入岩石条件的相似，试验中必须保证模型工具与岩石之间的接触应力水平接近钎杆冲击侵入时的水平。这可保证工具具有相同的循环耐久性，并使破碎单位体积岩石的能耗保持不变。

工具及钎杆侵入岩石过程的物理方程以泛函形式表示：

φ = (A, EME, μME, r, β, σk, EП, μП),     (1)

式中A、EME、μME、r、β、σk、EП、μП分别为冲击能量、工具的弹性模量和泊松比、模型工具及钎杆的圆柱段半径和尖端锥角、接触应力、岩石的弹性模量和泊松比。

决定侵入过程的各参数的量纲：

[β] = [L0M0T0] ⇒ P5,
[σk] = [L–1M1T–2] ⇒ P6,
[EП] = [L–1M1T–2] ⇒ P7,
[μП] = [L0M0T0] ⇒ P8,
[A] = [L2M1T–2] ⇒ P1,
[EME] = [L–1M1T–2] ⇒ P2,
[μME] = [L0M0T0] ⇒ P3,
[r] = [L1M0T0] ⇒ P4,     (2)

式中L为长度，M为质量，T为时间。

因此，完整量纲矩阵的规模为n×q，其中n = 8为决定侵入过程的参数总数，q = 3为参数的基本计量单位数。

从(2)中剔除无量纲参数（P3、P5和P8），并将量纲相同的参数归并为一个（本例中在P2、P6和P7中宜保留P6），得到如下形式的简化矩阵：

‖A‖ = ‖ 2   1   –2 ‖ ⇒ A
        ‖ –1   1   –2 ‖ ⇒ σk
        ‖ 1   0   0 ‖ ⇒ r     (3)

相似准则总数Nπ按Nπ = m – l确定（此处m和l分别为参数总数（A、σk和r）和独立参数数（A和r）），本例中为3 – 2 = 1。对于独立参数A和r，相似准则π的具体表达式为

π = P3(P1x, P2y)–1 = σk(Ax, ry)–1,     (4)

式中x和y为独立参数的未知指数，需确定以得到相似准则的具体形式。

由于相似准则为无量纲量，分子与分母的量纲必须相同，由关系式(4)可写出

[σk] = [A]x[r]y.     (5)

展开上式中各参数的量纲

[L–1M1T–2] = [L2M1T–2]x[L1M0T0]y     (6)

并求解所得方程组

2x + y = –1
x = 1
–2x = –2     (7)

得到x = 1，y = –3。

因此，模拟条件（πм）与钎杆工作条件（πп）的相似准则形式为

π = idem ⇔ πМ = πП ⇔ σk,МAМ–1rМ3 = σk,ПAП–1rП3     (8)

由此，为保证σк相等，得到

σk,М / σk,Н = (AМ / AП)·(rМ / rП)–3,     (9)

式中Aм和rм、Aп和rп分别为模型工具和液压破碎锤钎杆的冲击能量及圆柱段半径。

选取便于试验的模型工具下落高度hм = 42 mm，得到冲击能量Aм = 1.16 J（冲击头质量2.8 kg时）。将Aм值与液压破碎锤钎杆的Aп、rп值（JCB HM380液压破碎锤：Aп = 981 J，rп = 39 mm）一并代入(9)，确定满足相似条件的模型工具圆柱段半径rм = 4 mm。

因此，为模拟钎杆侵入岩石的条件，工具下落高度hм及其半径rм应分别为42 mm和4 mm，试验中即按此实施。

至于保证破岩能耗相等的问题，将试验条件下的该指标（根据文献［29］的数据可估计为14 MJ/m3）与液压破碎锤的相应指标（10.4 MJ/m3［16］）进行比较，表明二者数值接近。

因此，当试验中保证所确定的hм和rм值时，"模型冲击工具"–"岩石"与"钎杆"–"岩石"两个系统的力学相似和能量相似得以满足。

[图3 — 见原文PDF第9页] 不同冲击能量下38ХМ钢模型工具累计质量损失与冲击次数n的关系：1 — Aм1 = 1.16 J；2 — Aм2 = 1.74 J；3 — Aм3 = 2.32 J；4 — Aм4 = 2.90 J

试验结果

以38ХМ钢工具为例，冲击能量Aм对模型工具质量损失及其冲击–磨料磨损强度Kм影响的试验结果见图3。

结果表明，随着冲击能量Aм的增大，所有钢种模型工具的ΣΔm = f(n)曲线均向上移动（图3），冲击–磨料磨损强度Kм增大。同时，Kм与Aм呈正比关系：Aм增大n倍时，Kм也几乎增大相同倍数。例如，当冲击功由Aм1 = 1.16 J增至Aм4 = 2.9 J，即增大2.5倍时，磨损强度之比Kм4/Kм1对38ХМ钢为2.41，У8А为2.63，Х12МФ为2.37（图4），即实际上满足等式

KMi = KM1 · AMi / AM1     (10)

鉴于试验中满足相似准则(9)，认为所建立的Kм与Aм之间的关系(10)可用于根据相应材料模型工具的磨损强度Kм以及钎杆冲击能量Aп与工具冲击能量Aм之比，确定液压破碎锤钎杆的冲击–磨料磨损强度Kп：

KП = KM · AП / AM     (11)

液压破碎锤钎杆冲击–磨料磨损强度及其工作寿命的确定

[图5 — 见原文PDF第10页] 所采用的钎杆钝化半径随磨损变化的示意图

认为钎杆的极限状态（工作寿命终止）出现在其尖端完全磨损时，即钎杆尖端半球形钝化半径rсф与其圆柱段半径相等时：

rсфк = rп     (12)

假定绝大部分磨损金属来自钎杆与岩石的接触区，计算了钎杆对花岗岩块所需施加的冲击次数N*，使半径rсф由rсф0 = 13 mm（初始钎杆的钝化半径）变化至rсфк = rп = 39 mm，其依据是每次冲击使半球体积减少与Kп相对应的量v'：

v' = KП / ρ     (13)

式中ρ为钎杆材料密度（所有钢种均为7.85·103 kg/m3）（图5）。将所确定的N*值作为钎杆的工作寿命。

表中列出了试验确定的模型工具Kм值（Aм1 = 1.16 J时）、据此按(18)计算的磨损强度Kп（Aп = 981 J时）、与Kп相对应的体积v'以及所确定的N*值。

由表中数据比较可见，若以耐磨性更高的У8А和Х12МФ钢替代传统钎杆材料38ХМ钢，工具工作寿命将由4.3·105次冲击分别提高到6.1·105次和8.6·105次，即提高1.4倍和2倍。

与经标准热处理的同类钎杆相比，对所研究各钢种工具进行冷处理和深冷处理，可使钎杆在完全钝化前所能施加的冲击次数提高1.1至2倍。

冷处理的上述积极作用可解释为：高碳钢У8А（~0.8%C）和Х12МФ（~1.5%C）工具在零下温度保持，可显著降低其组织中"软"残余奥氏体的含量，而淬火后这些奥氏体大量残留。同时，冷处理还促使合金钢38ХМ和Х12МФ工具组织中碳化物含量增加。而且，冷处理温度越低，其效果越高［29］。

主要结论

  • 提出了一种实验室试验方法，用于在模拟液压破碎锤钎杆侵入岩石时磨损条件的情况下，研究不同钢种及不同热处理的模型冲击工具的磨损规律。
  • 三种牌号工具钢制成的模型工具试验结果表明，其侵入花岗岩块时的冲击–磨料磨损强度Kм随冲击能量增大而呈正比增大。
  • 根据所确定的模型工具磨损强度Kм及其与冲击能量的关系形式，计算了由三种牌号钢制成并经三种热处理的JCB HM380液压破碎锤钎杆侵入花岗岩时的冲击–磨料磨损强度Kп及工作寿命。
  • 结果表明，若以耐磨性更高的У8А和Х12МФ钢替代传统钎杆材料38ХМ钢，钎杆在尖端完全磨损前所能施加的冲击次数（钎杆工作寿命）将提高1.4倍和2倍。与标准热处理相比，对上述钢制工具进行冷处理和深冷处理可使钎杆工作寿命提高1.1至2倍。
